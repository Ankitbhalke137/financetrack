# PRODUCT SPECIFICATION DOCUMENT & AI CODING INSTRUCTIONS

## 1. Project Goal
Build a responsive, full-stack Web Application (PWA) for Personal Finance & Loan Tracking.
- Frontend: Web interface for mobile and desktop.
- Authentication: Google Auth (OAuth 2.0).
- Database/Backend: Google Sheets API (User's own Google Sheet acts as the database).
- Primary Capabilities: Track Income ("Add Money"), Daily Expenses, Loans/EMIs, and Monthly Category Budgets in real-time.

---

## 2. Recommended Tech Stack
- Framework: Next.js (App Router, TypeScript)
- Styling: Tailwind CSS + Lucide React Icons + shadcn/ui
- Auth & API Integration: NextAuth.js (Auth.js) with Google OAuth 2.0
- Google Sheets SDK: `googleapis` (npm package)
- Charts: Recharts / Chart.js for financial visualizers

---

## 3. Google OAuth & Permissions Scope
Configure NextAuth with the Google Provider including the following OAuth scope:
- `https://www.googleapis.com/auth/userinfo.profile`
- `https://www.googleapis.com/auth/userinfo.email`
- `https://www.googleapis.com/auth/spreadsheets` (Required to read/write transactions directly to the logged-in user's Google Sheet)

On initial user sign-in:
1. Check if a spreadsheet named "Personal_Finance_Tracker" exists in the user's drive.
2. If it does not exist, automatically create it using the Google Sheets API and seed it with standard headers and formulas.

---

## 4. Google Sheet Data Structure & Schema

The app must read and append rows to 3 specific tabs in the user's Google Sheet:

### Tab 1: `Transactions` (Raw Data)
Columns: `Txn_ID` | `Date` | `Type` | `Category` | `Amount` | `Notes` | `Loan_Ref_ID`
- Type values: `Income`, `Add Money`, `Expense`, `Loan Payment`

### Tab 2: `Loans` (Liability Tracking)
Columns: `Loan_ID` | `Loan_Name` | `Original_Amount` | `Monthly_EMI` | `Total_Paid` | `Remaining_Balance`
- `Total_Paid` Formula: `=SUMIFS(Transactions!E:E, Transactions!C:C, "Loan Payment", Transactions!G:G, A2)`
- `Remaining_Balance` Formula: `=C2 - E2`

### Tab 3: `Budgets` (Limits & Categories)
Columns: `Category` | `Monthly_Budget_Limit` | `Actual_Spent` | `Remaining`
- `Actual_Spent` Formula: `=SUMIFS(Transactions!E:E, Transactions!D:D, A2, Transactions!C:C, "Expense")`

## 5. App User Interface (UI/UX) Specs

### Screen 1: Login / Onboarding
- "Sign in with Google" button.
- Value proposition display: "Track money effortlessly. Your data stays 100% in your Google Sheets."

### Screen 2: Main Dashboard
- **Header:** User Profile Picture, Name, and "Connected to Google Sheet" live status badge.
- **Top Metrics Cards:**
  1. *Available Wallet Cash:* Total Income - Total Expenses - Total EMI Payments.
  2. *Spent This Month:* Actual vs. Budget progress bar.
  3. *Total Outstanding Loans:* Sum of active loan remaining balances.
- **Floating Action Bar / Quick Log Button (`+`):**
  - Modal with 3 tab triggers: `[ Add Money / Income ]`, `[ Expense ]`, `[ Pay Loan EMI ]`.
  - Fields: Amount, Category dropdown, Date (default today), Notes, and Submit.
  - Submitting sends an API call (`POST /api/transactions`) that appends the row to the Google Sheet instantly.

### Screen 3: Loans & Debt Payoff Tracker
- Card view of all active loans (Car Loan, Personal Loan, Home Loan).
- Progress bar for each loan: `Paid Amount` vs. `Original Amount`.
- "Log EMI Payment" button pre-fills the transaction modal with the selected `Loan_Ref_ID`.

### Screen 4: Transaction History & Excel Sync Feed
- Table view with live search, date picker filter, and category pills.
- Quick link: "Open Master Spreadsheet in Google Drive".

## 6. API Route Structure (Next.js Server Actions / API Routes)
- `POST /api/auth/[...nextauth]` - Google OAuth session handling.
- `GET /api/dashboard` - Fetches aggregated summary numbers from the user's sheet.
- `POST /api/transactions` - Appends a new row to the `Transactions` sheet tab.
- `GET /api/loans` - Reads all active loan records.
- `POST /api/loans` - Creates a new loan entry in the `Loans` sheet tab.

Please execute this project in the following order:
1. Set up Next.js App Router project with Tailwind CSS and shadcn/ui.
2. Implement NextAuth with Google OAuth 2.0 configuration and OAuth refresh tokens for Google Sheets scope.
